# Changelog

## Copy Box: New clip, expandable tiles, dates, fast start, small APK (PR #1)

Not build-tested here (no Flutter/Android SDK); APK/AAB sizes not measured. See BUILD.md §8.

1. **New clip replaces Save clipboard:** History has one extended FAB, "New clip" (opens the editor), and no app-bar edit icon. The empty state depends on whether auto-save is on. Auto-save skips now offer **Save anyway**. The tile is called "Save to Copy Box". Every text now says the clipboard is read only when the app opens (auto-save) or from the tile.
2. **Clip tiles:** no avatar; the type word uses the category colour. Tap expands/collapses (selectable, capped at 10,000 chars). Copying only via the copy button or the long-press menu. The star sits next to the copy button.
3. **Dates:** the last line of each tile shows "Today · 12:48 PM" / "Yesterday · …" / "15 Nov 2026 · …" in local time. The meta line is "Type · Source".
4. **Fast start:** `runApp` first. Settings and the database open in parallel during the splash; ads consent runs in the background. The splash lasts 1.5–3 s. History pages are 50 clips. DB v2 adds an index on `created_at`. The native inbox drain moved off the main thread.
5. **Small APK:** release arm64, AAB and size-report Codemagic workflows. R8, resource shrinking, English-only resources, arm64 filter, packaging excludes.

## 1.0.0 (unreleased): security and functionality review

**Not build-tested.** No Flutter or Android SDK was available. Run `flutter analyze`, `flutter test` and the README device test plan before release.

### Security
- **Fixed:** the native inbox (Quick Settings tile, Share, text selection) was imported into SQLite without the `SensitiveDetector`. All automatic paths now go through one gate, `ClipsController._autoFilterReason`. System-flagged clips are always refused; the heuristics follow "Skip passwords and codes".
- Skipped inbox items are held in memory only, for 2 minutes, behind a "Save anyway" snackbar action.
- Skipped auto-save clips now show a message instead of being dropped silently.
- "Save clipboard" always asks before storing sensitive-looking text, whatever the setting.
- Copying a sensitive-looking clip out of Copy Box sets `EXTRA_IS_SENSITIVE` (new native `copyText`).
- Native side rejects text over 100,000 characters before queueing it, so the exported share/selection activity can't be fed oversized input.
- `tool/check_structure.py` enforces these invariants.

### Functionality
- `CaptureActivity`: removed `val intent = intent` self-shadowing, a likely Kotlin compile error.
- Tile: retries the read once after 200 ms if focus is still settling. Android 14+ `PendingIntent` gets the creator background-launch opt-in.
- Tile, share and selection toasts now say "Sent to Copy Box", because the text is filtered later in Flutter.
- Folder ids are validated before every write. Previously, saving from the editor after the selected folder was deleted hit a foreign-key failure.
- A failed database open is no longer cached forever. Init failure shows a message and disables auto-capture.
- Snackbars support actions (`AppMessage`).
